## Vue d'ensemble

### Le défi

Les utilisateurs doivent pouvoir :
- Voir les états de survol (`hover`) et de focus pour tous les éléments interactifs de la page.
- Profiter d'une mise en page entièrement responsive (ordinateur et mobile).

## Mon processus

### Construit avec

- Balisage HTML5 sémantique
- Propriétés personnalisées CSS (Variables)
- Flexbox
- Unités responsives et modernes

### Ce que j'ai appris

Ce projet m'a permis de perfectionner la structure de mes composants en HTML sémantique, de gérer les états interactifs (`hover` et `focus`) avec accessibilité, et de structurer un design épuré en utilisant CSS Flexbox.
